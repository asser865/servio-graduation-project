# servio-graduation-project
AI-powered home maintenance and finishing services platform (Graduation Project)

## Project Structure
- frontend-web: Web application (React / Next.js)
- mobile-app: Mobile application (Flutter)
- backend: RESTful API (Node.js / Express)
- ai-service: AI & ML services (Python)
- docs: Documentation, diagrams, reports
